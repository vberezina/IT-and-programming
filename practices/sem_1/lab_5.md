## Учебная задача

### 1. Формулировка задачи

Создайте файл `collections.py` и напишите программу для обработки списка музыкальных треков. Каждый трек должен быть представлен словарем с ключами `title`, `artist` и `duration`. Длительность трека хранится в секундах.

Программа должна выполнить следующие действия:

1. Сформировать исходный список треков.
2. Показать обращение к элементу списка по индексу.
3. Получить срез списка.
4. Продемонстрировать добавление, изменение и удаление элемента списка.
5. Обойти коллекцию в цикле.
6. Сформировать множество исполнителей, чтобы удалить дубликаты.
7. Проверить вхождение элемента во множество.
8. Выполнить операции над множествами: пересечение, разность и объединение.
9. Отфильтровать треки по условию: длительность больше 200 секунд.
10. Сформировать словарь суммарной длительности треков по каждому исполнителю.
11. Продемонстрировать добавление элементов в словарь, доступ по ключу, изменение значения, получение ключей и значений.
12. Преобразовать данные в новую коллекцию: список строк вида `Название - Исполнитель - минуты:секунды`.
13. Отсортировать треки по названию.
14. Отсортировать треки по длительности по убыванию.
15. Вывести исходную коллекцию и все полученные результаты.

### 2. Ожидаемый результат

В результате выполнения должен быть создан файл `collections.py`. При запуске программы на экран должны выводиться:

- исходный список треков;
- первый трек, полученный по индексу;
- срез из первых трех треков;
- список после добавления нового трека;
- измененный трек;
- удаленный трек;
- список после удаления трека;
- множество исполнителей без дубликатов;
- результат проверки вхождения исполнителя во множество;
- результаты операций над множествами;
- список треков длительностью больше 200 секунд;
- словарь суммарной длительности по исполнителям;
- словарь с информацией о плейлисте;
- ключи и значения словаря с информацией о плейлисте;
- преобразованный список треков в текстовом формате;
- список треков, отсортированный по названию;
- список треков, отсортированный по длительности по убыванию;
- общая длительность всех треков в секундах.

Для предложенных данных ожидаются следующие ключевые результаты:

- общая длительность всех треков после изменения длительности одного трека: `1010` секунд;
- количество треков длительностью больше 200 секунд: `3`;
- множество исполнителей должно содержать `Aurora`, `Vector`, `North`;
- словарь суммарной длительности должен содержать значения:
  - `Aurora`: `459`;
  - `Vector`: `381`;
  - `North`: `170`.

Порядок вывода элементов множества может отличаться, так как множества в Python не гарантируют порядок элементов.

### 4. Полный код программы

```python
# Файл: collections.py
# Программа обрабатывает список музыкальных треков.
# Каждый трек представлен словарем с ключами:
# "title" - название трека,
# "artist" - исполнитель,
# "duration" - длительность в секундах.

# Создаем исходный список треков.
# Список содержит несколько словарей, чтобы показать работу
# со списком, словарями и последующим множеством.
tracks = [
    {"title": "Morning", "artist": "Aurora", "duration": 215},
    {"title": "Night", "artist": "Vector", "duration": 180},
    {"title": "Sea", "artist": "Aurora", "duration": 244},
    {"title": "Wind", "artist": "North", "duration": 165},
    {"title": "Rain", "artist": "Vector", "duration": 201},
]

# Выводим исходную коллекцию, чтобы видеть начальное состояние данных.
print("Исходный список треков:")
for track in tracks:
    print(track)

# Обращение к элементу списка по индексу.
# Индекс 0 соответствует первому треку в списке.
first_track = tracks[0]
print("\nПервый трек, полученный по индексу 0:")
print(first_track)

# Получение среза списка.
# Срез tracks[:3] возвращает первые три элемента списка.
first_three_tracks = tracks[:3]
print("\nСрез: первые три трека:")
for track in first_three_tracks:
    print(track)

# Демонстрация добавления нового элемента в список.
# Создаем новый словарь с треком и добавляем его в конец списка.
new_track = {"title": "Demo", "artist": "Test", "duration": 190}
tracks.append(new_track)
print("\nСписок после добавления нового трека:")
for track in tracks:
    print(track)

# Демонстрация изменения элемента списка.
# Меняем длительность трека с индексом 3.
# Под индексом 3 находится трек Wind.
tracks[3]["duration"] = 170
print("\nСписок после изменения длительности трека с индексом 3:")
print(tracks[3])

# Демонстрация удаления элемента из списка.
# Метод pop() удаляет последний элемент и возвращает его.
# Так как перед этим был добавлен трек Demo, удалится именно он.
removed_track = tracks.pop()
print("\nУдаленный трек:")
print(removed_track)

# Выводим список после удаления последнего трека.
print("\nСписок после удаления последнего трека:")
for track in tracks:
    print(track)

# Формируем множество исполнителей.
# Множество автоматически удаляет дубликаты, поэтому один исполнитель
# сохранится только один раз, даже если у него несколько треков.
artists = set()

# В цикле обходим список треков и добавляем имена исполнителей во множество.
for track in tracks:
    artists.add(track["artist"])

# Выводим множество исполнителей после удаления дубликатов.
print("\nМножество исполнителей после удаления дубликатов:")
print(artists)

# Проверяем вхождение элемента во множество.
# Оператор in возвращает True, если элемент присутствует во множестве.
has_aurora = "Aurora" in artists
print("\nЕсть ли исполнитель Aurora в множестве:", has_aurora)

# Создаем дополнительное множество избранных исполнителей,
# чтобы показать операции объединения, пересечения и разности.
favorite_artists = {"Aurora", "Luna"}
print("Избранные исполнители:", favorite_artists)

# Пересечение множеств.
# Результат содержит только тех исполнителей, которые есть
# и в плейлисте, и в списке избранных.
common_artists = artists & favorite_artists
print("\nПересечение с избранными исполнителями:", common_artists)

# Разность множеств.
# Результат содержит исполнителей из плейлиста,
# которых нет в множестве избранных.
not_favorite_artists = artists - favorite_artists
print("Исполнители из плейлиста, которых нет в избранном:", not_favorite_artists)

# Объединение множеств.
# Результат содержит всех исполнителей из обоих множеств без дубликатов.
all_artists = artists | favorite_artists
print("Объединение исполнителей плейлиста и избранного:", all_artists)

# Фильтрация данных.
# Отбираем треки, длительность которых больше 200 секунд.
# Используем генератор списка.
long_tracks = [track for track in tracks if track["duration"] > 200]
print("\nТреки длительностью больше 200 секунд:")
for track in long_tracks:
    print(track)

# Создаем словарь суммарной длительности треков по исполнителям.
# Ключом будет имя исполнителя, значением - суммарная длительность.
total_by_artist = {}

# Обходим список треков и заполняем словарь.
for track in tracks:
    artist = track["artist"]
    duration = track["duration"]

    # Если исполнитель уже есть в словаре,
    # увеличиваем его суммарную длительность.
    if artist in total_by_artist:
        total_by_artist[artist] += duration
    # Если исполнителя еще нет, добавляем первую запись.
    else:
        total_by_artist[artist] = duration

# Выводим словарь суммарной длительности по исполнителям.
print("\nСловарь суммарной длительности по исполнителям:")
print(total_by_artist)

# Создаем отдельный словарь с информацией о плейлисте,
# чтобы продемонстрировать операции со словарем.
playlist_info = {}

# Добавление элементов в словарь.
playlist_info["name"] = "My Playlist"
playlist_info["track_count"] = len(tracks)
playlist_info["favorite"] = False

# Демонстрация доступа по ключу.
playlist_name = playlist_info["name"]
print("\nИмя плейлиста, полученное по ключу:")
print(playlist_name)

# Демонстрация изменения значения.
# Меняем значение по ключу favorite.
playlist_info["favorite"] = True

# Выводим словарь после добавления и изменения значений.
print("\nСловарь с информацией о плейлисте после добавления и изменения:")
print(playlist_info)

# Получаем ключи словаря playlist_info.
print("\nКлючи словаря playlist_info:")
for key in playlist_info.keys():
    print(key)

# Получаем значения словаря playlist_info.
print("\nЗначения словаря playlist_info:")
for value in playlist_info.values():
    print(value)

# Преобразование данных.
# Формируем новую коллекцию, где каждый трек представлен строкой.
# Формат строки: "Название - Исполнитель - минуты:секунды".
# Минуты вычисляются делением нацело на 60.
# Секунды вычисляются как остаток от деления на 60.
# Формат :02d добавляет ноль спереди, если секунд меньше 10.
formatted_tracks = [
    f"{track['title']} - {track['artist']} - {track['duration'] // 60}:{track['duration'] % 60:02d}"
    for track in tracks
]

# Выводим преобразованный список треков.
print("\nПреобразованный список треков в текстовом формате:")
for item in formatted_tracks:
    print(item)

# Сортировка данных по названию трека.
# Функция sorted() не изменяет исходный список, а возвращает новый.
# Параметр key задает критерий сортировки: значение поля title.
sorted_tracks_by_title = sorted(tracks, key=lambda track: track["title"])
print("\nСписок треков после сортировки по названию:")
for track in sorted_tracks_by_title:
    print(track)

# Дополнительная сортировка по длительности по убыванию.
# Параметр reverse=True изменяет порядок сортировки на обратный.
sorted_tracks_by_duration = sorted(
    tracks,
    key=lambda track: track["duration"],
    reverse=True
)
print("\nСписок треков после сортировки по длительности (по убыванию):")
for track in sorted_tracks_by_duration:
    print(track)

# Вычисляем общую длительность всех треков.
# Используем цикл и переменную-накопитель.
total_duration = 0
for track in tracks:
    total_duration += track["duration"]

# Выводим итоговую общую длительность.
print("\nОбщая длительность всех треков в секундах:", total_duration)
```
