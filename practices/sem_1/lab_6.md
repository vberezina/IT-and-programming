## Учебная задача

### 1. Формулировка задачи

Создайте отдельный рабочий каталог для выполнения задания. В этом каталоге подготовьте два входных файла:

1. Текстовый файл `feedback.txt` в кодировке UTF-8.  
   Файл должен содержать не менее пяти осмысленных строк с отзывами или сообщениями. Часть строк может содержать упоминания доставки в любых формах, например: «доставка», «доставку», «доставки».

2. CSV-файл `orders.csv` в кодировке UTF-8.  
   Файл должен содержать не менее пяти записей о заказах и обязательные столбцы:

   ```csv
   order_id,amount,status
   ```

   Поле `order_id` — идентификатор заказа, `amount` — сумма заказа, `status` — статус заказа. Примеры статусов: `доставлен`, `отменён`, `в пути`.

Напишите программу на Python, которая выполняет следующие действия:

- читает текстовый файл `feedback.txt` в кодировке UTF-8;
- считает количество непустых строк в текстовом файле;
- считает количество строк, содержащих подстроку `доставк` без учёта регистра;
- читает CSV-файл `orders.csv` с использованием модуля `csv`;
- находит заказы со статусом `доставлен`;
- вычисляет количество доставленных заказов, общую сумму доставленных заказов и среднюю сумму доставленного заказа;
- пропускает строки заказов с некорректной суммой и подсчитывает количество таких строк;
- сохраняет итог в файл `report.json` с использованием модуля `json`;
- выводит краткий результат работы в консоль;
- обрабатывает ошибки: отсутствие файла, пустой файл, отсутствие обязательных столбцов, некорректные числовые данные.

Программа не должна изменять входные файлы. Файл результата `report.json` может перезаписываться при повторном запуске.

### 2. Ожидаемый результат

После выполнения программы в рабочем каталоге должны остаться входные файлы и появиться выходной файл `report.json`.

Файл `report.json` должен содержать следующие поля:

```json
{
  "total_feedback_lines": 6,
  "delivery_mentions": 3,
  "delivered_orders_count": 3,
  "delivered_total_amount": 1961.5,
  "average_delivered_amount": 653.83,
  "invalid_orders_count": 0
}
```

Пример ожидаемого вывода в консоль:

```text
Обработано непустых строк обратной связи: 6
Строк с упоминанием доставки: 3
Доставленных заказов: 3
Итоговая сумма доставленных заказов: 1961.50
Средняя сумма доставленного заказа: 653.83
Некорректных строк заказов: 0
```

Если во входных данных есть некорректные строки, программа должна завершить работу без аварийной ошибки, указать количество некорректных строк и сохранить корректно обработанную часть данных.

### 4. Полный код программы

```python
# Программа для обработки отзывов и заказов.
# Читает текстовый файл feedback.txt и CSV-файл orders.csv,
# считает показатели и сохраняет итог в файл report.json.

import csv
import json
import sys
from pathlib import Path

# Имена входных файлов и выходного файла.
FEEDBACK_FILE = "feedback.txt"
ORDERS_FILE = "orders.csv"
REPORT_FILE = "report.json"

# Часть слова, которая позволяет находить разные формы слова «доставка»:
# «доставка», «доставку», «доставки» и т. п.
KEYWORD = "доставк"

# Статус заказа, который считается доставленным.
DELIVERED_STATUS = "доставлен"

# Обязательные столбцы CSV-файла с заказами.
REQUIRED_COLUMNS = {"order_id", "amount", "status"}


def read_feedback_lines(file_name):
    """
    Читает текстовый файл в кодировке UTF-8.

    Если файл отсутствует или полностью пустой, функция создаёт ошибку,
    которую дальше обрабатывает функция main().
    """

    # Создаём объект пути к файлу.
    path = Path(file_name)

    # Проверяем существование файла, чтобы вывести понятное сообщение.
    if not path.exists():
        raise FileNotFoundError(f"Файл {file_name} не найден.")

    # Открываем файл для чтения в кодировке UTF-8.
    with path.open("r", encoding="utf-8") as file:
        lines = file.readlines()

    # Если строк нет или все строки состоят только из пробелов и переводов строк,
    # считаем файл пустым.
    if len(lines) == 0 or all(line.strip() == "" for line in lines):
        raise ValueError(
            f"Файл {file_name} пустой или содержит только пустые строки."
        )

    return lines


def process_feedback(lines):
    """
    Обрабатывает строки текстового файла.

    Считает:
    1) количество непустых строк;
    2) количество строк, содержащих подстроку «доставк» без учёта регистра.
    """

    total_non_empty = 0
    delivery_mentions = 0

    for line in lines:
        # Удаляем лишние пробелы и символы перевода строки по краям.
        text = line.strip()

        # Если строка пустая, не учитываем её.
        if text == "":
            continue

        # Увеличиваем количество непустых строк.
        total_non_empty += 1

        # Приводим строку к нижнему регистру, чтобы поиск не зависел от регистра.
        lower_text = text.lower()

        # Если строка содержит нужную часть слова, увеличиваем счётчик упоминаний.
        if KEYWORD.lower() in lower_text:
            delivery_mentions += 1

    return total_non_empty, delivery_mentions


def read_orders(file_name):
    """
    Читает CSV-файл с заказами.

    Проверяет:
    1) существование файла;
    2) наличие заголовка;
    3) наличие обязательных столбцов;
    4) наличие хотя бы одной строки данных после заголовка.
    """

    path = Path(file_name)

    # Проверяем существование CSV-файла.
    if not path.exists():
        raise FileNotFoundError(f"Файл {file_name} не найден.")

    # Параметр newline="" нужен для корректной работы модуля csv.
    with path.open("r", encoding="utf-8", newline="") as file:
        reader = csv.DictReader(file)

        # Если файл полностью пустой, заголовков не будет.
        if reader.fieldnames is None:
            raise ValueError(
                f"Файл {file_name} пустой или не содержит заголовок CSV."
            )

        # Собираем фактические имена столбцов.
        # Приводим их к нижнему регистру и удаляем лишние пробелы.
        actual_columns = set()
        for name in reader.fieldnames:
            if name is not None:
                actual_columns.add(name.strip().lower())

        # Проверяем, есть ли все обязательные столбцы.
        missing_columns = REQUIRED_COLUMNS - actual_columns
        if missing_columns:
            missing_text = ", ".join(sorted(missing_columns))
            raise ValueError(
                f"В файле {file_name} отсутствуют обязательные столбцы: {missing_text}."
            )

        rows = []

        # Читаем строки данных.
        for row in reader:
            clean_row = {}

            # Чистим ключи и значения от лишних пробелов.
            for key, value in row.items():
                # Если в CSV есть лишние поля без имени, пропускаем их.
                if key is None:
                    continue

                clean_key = key.strip().lower()

                # Если значение отсутствует или не является строкой,
                # заменяем его пустой строкой.
                if isinstance(value, str):
                    clean_value = value.strip()
                else:
                    clean_value = ""

                clean_row[clean_key] = clean_value

            rows.append(clean_row)

    # Если после заголовка нет ни одной строки данных, считаем файл пустым.
    if len(rows) == 0:
        raise ValueError(
            f"Файл {file_name} не содержит строк данных после заголовка."
        )

    return rows


def process_orders(rows):
    """
    Обрабатывает заказы из CSV.

    Считает:
    1) количество доставленных заказов;
    2) сумму доставленных заказов;
    3) среднюю сумму доставленного заказа;
    4) количество строк с некорректной суммой.
    """

    delivered_count = 0
    delivered_total = 0.0
    invalid_rows = 0

    for row in rows:
        # Получаем статус заказа и приводим его к нижнему регистру.
        status = row.get("status", "").lower()

        # Получаем сумму заказа.
        # Заменяем запятую на точку, чтобы поддерживать десятичный разделитель.
        amount_text = row.get("amount", "").replace(",", ".")

        # Пытаемся преобразовать сумму в число с плавающей точкой.
        try:
            amount = float(amount_text)
        except ValueError:
            # Если сумма не является числом, увеличиваем счётчик ошибок
            # и переходим к следующей строке.
            invalid_rows += 1
            continue

        # Отрицательная сумма считается некорректной.
        if amount < 0:
            invalid_rows += 1
            continue

        # Учитываем только заказы со статусом «доставлен».
        if status == DELIVERED_STATUS:
            delivered_count += 1
            delivered_total += amount

    # Считаем среднюю сумму только в том случае, если есть доставленные заказы.
    if delivered_count > 0:
        average_amount = delivered_total / delivered_count
    else:
        average_amount = 0.0

    # Округляем денежные показатели до двух знаков после запятой.
    delivered_total = round(delivered_total, 2)
    average_amount = round(average_amount, 2)

    return delivered_count, delivered_total, average_amount, invalid_rows


def save_report(file_name, report):
    """
    Сохраняет словарь report в JSON-файл.

    Параметр ensure_ascii=False нужен для того, чтобы кириллица
    сохранялась в читаемом виде, а не в виде escape-последовательностей.
    """

    with open(file_name, "w", encoding="utf-8") as file:
        json.dump(report, file, ensure_ascii=False, indent=2)


def main():
    """
    Главная функция программы.

    Читает данные, обрабатывает ошибки, считает результат,
    сохраняет отчёт и выводит краткую информацию в консоль.
    """

    try:
        # Читаем входные файлы.
        feedback_lines = read_feedback_lines(FEEDBACK_FILE)
        orders_rows = read_orders(ORDERS_FILE)

    except FileNotFoundError as error:
        # Обработка отсутствия файла.
        print(f"Ошибка: {error}")
        return 1

    except ValueError as error:
        # Обработка пустых файлов и отсутствия обязательных столбцов.
        print(f"Ошибка данных: {error}")
        return 1

    except csv.Error as error:
        # Обработка ошибок формата CSV.
        print(f"Ошибка формата CSV: {error}")
        return 1

    # Обрабатываем текстовый файл.
    total_feedback, delivery_mentions = process_feedback(feedback_lines)

    # Обрабатываем CSV-файл.
    delivered_count, delivered_total, average_amount, invalid_rows = process_orders(
        orders_rows
    )

    # Формируем итоговый отчёт.
    report = {
        "total_feedback_lines": total_feedback,
        "delivery_mentions": delivery_mentions,
        "delivered_orders_count": delivered_count,
        "delivered_total_amount": delivered_total,
        "average_delivered_amount": average_amount,
        "invalid_orders_count": invalid_rows,
    }

    # Сохраняем отчёт в JSON-файл.
    try:
        save_report(REPORT_FILE, report)
    except OSError as error:
        # Обработка ошибок записи, например отсутствия прав на запись.
        print(f"Ошибка сохранения отчёта: {error}")
        return 1

    # Выводим краткий результат работы программы в консоль.
    print(f"Обработано непустых строк обратной связи: {total_feedback}")
    print(f"Строк с упоминанием доставки: {delivery_mentions}")
    print(f"Доставленных заказов: {delivered_count}")
    print(f"Итоговая сумма доставленных заказов: {delivered_total:.2f}")
    print(f"Средняя сумма доставленного заказа: {average_amount:.2f}")
    print(f"Некорректных строк заказов: {invalid_rows}")

    # Код 0 означает успешное завершение программы.
    return 0


# Точка входа в программу.
if __name__ == "__main__":
    sys.exit(main())
```
