### Обязательный минимум

1. Что такое коммит в Git и что он сохраняет?

2. Чем отличается абсолютный путь к файлу от относительного в командной строке?
3. В чём главное отличие списка (`list`) от кортежа (`tuple`) в Python?
4. Какие типы данных разрешено использовать в качестве ключей в словаре (`dict`) в Python?

25. Операции и выражения в Python: арифметические, логические операции, сравнение и приоритет.  
25. Работа со строками в Python: поиск, разделение, замена, форматирование и анализ текстовых данных.

26. Ввод и вывод данных в Python: функции `input()` и `print()`, форматированный вывод.  
27. Алгоритмические конструкции: условия, циклы и управление выполнением программы.  
28. Функции в Python: параметры, возвращаемые значения, область видимости и декомпозиция задач.  
28. Область видимости переменных в Python: локальные и глобальные переменные, доступ к переменным из функций.
29. Структуры данных в Python: списки, кортежи, словари, множества.  
30. Генераторы коллекций в Python: создание списков, словарей и множеств на основе условий и преобразований.

### Практические задания

1. Запишите последовательность команд терминала и Git, чтобы создать каталог `project`, перейти в него, инициализировать репозиторий, добавить файл `README.md` и создать коммит с сообщением `Initial commit`.  

2. Составьте фрагмент файла `README.md` на Markdown: заголовок первого уровня с названием проекта; маркированный список из трёх возможностей проекта; ссылку на сайт; блок кода с командой запуска.  

3. По данным «Математика — 5», «Физика — 4», «Информатика — 5» запишите HTML-таблицу с заголовком таблицы и телом таблицы, используя теги `table`, `thead`, `tbody`, `tr`, `th`, `td`.  


4. Запишите CSS-правила для класса `.card`: ширина 300 пикселей, внутренний отступ 16 пикселей, сплошная серая рамка толщиной 1 пиксель, скругление углов 8 пикселей и тень.  
  

5. Напишите программу на Python, которая запрашивает у пользователя два целых числа и выводит их сумму, разность и произведение с поясняющим текстом.  

6. Напишите функцию на Python, которая принимает целое неотрицательное число `n` и возвращает сумму его цифр без использования строк, списков и других коллекций.  

7. Напишите функцию на Python, которая принимает список целых чисел и возвращает новый список, содержащий только чётные элементы исходного списка.  

8. Напишите функцию на Python, которая принимает список словарей вида:

    ```python
    {"name": "Иван", "score": 85}
    ```

    и возвращает средний балл по всем записям. Если список пуст, функция должна вернуть `0`.  

9. Напишите функцию на Python, которая читает файл `tasks.json`, содержащий список задач вида:

    ```json
    [
        {"title": "Купить хлеб", "done": true},
        {"title": "Сделать отчёт", "done": false}
    ]
    ```

    и возвращает список только невыполненных задач. Предусмотрите обработку ситуации, когда файл не найден.


10. Напишите программу, которая запрашивает у пользователя целое число и выводит текстовую характеристику числа: положительное, отрицательное или нулевое, а также чётное или нечётное.

11. Напишите функцию, которая принимает натуральное число и возвращает сумму его цифр. При решении нельзя использовать преобразование числа в строку.

12. Напишите функцию, которая принимает целое неотрицательное число и возвращает его факториал. Реализуйте вычисление с помощью цикла, без использования рекурсии.

13. Напишите программу, которая запрашивает у пользователя числа до тех пор, пока не будет введён ноль. После завершения ввода программа должна вывести количество введённых чисел и их сумму.

14. Напишите функцию, которая принимает список чисел и возвращает новый список, содержащий только те элементы исходного списка, которые больше среднего арифметического всех элементов исходного списка.

15. Напишите функцию, которая принимает текстовую строку и возвращает словарь, в котором для каждого слова указано количество его повторений в тексте. Сравнение слов должно выполняться без учёта регистра.

16. Напишите функцию, которая принимает список словарей с данными о студентах. Каждый словарь содержит имя студента и его балл. Функция должна вернуть список имён студентов, отсортированный по убыванию балла.

17. Напишите функцию, которая принимает два списка значений и возвращает список элементов, которые присутствуют в обоих списках, без повторений.

18. Напишите функцию, которая принимает путь к текстовому файлу и возвращает количество строк, количество слов и количество символов в этом файле. Если файл не найден, функция должна вернуть нулевые значения.
