## Учебная задача

### 1. Формулировка задачи

Создайте базовую веб-страницу на одну из предложенных тем и оформите её средствами CSS. Страница должна быть посвящена выбранному варианту, например кулинарной странице, туристическому маршруту, книжной полке, музыкальному проекту, спортивному клубу, учебному курсу, магазину техники, новостной странице, портфолио или городскому фестивалю.

Необходимо подготовить каталог проекта, содержащий файл `index.html` и отдельный файл стилей `css/style.css`. HTML-документ должен иметь корректную структуру: объявление типа документа, элемент `html` с атрибутом `lang="ru"`, головную часть с метаданными и видимую часть с контентом.

Страница должна содержать:

- один заголовок верхнего уровня `h1`;
- не менее двух подзаголовков `h2` или `h3`;
- не менее трёх абзацев текста;
- не менее трёх гиперссылок, из которых одна ведёт на внешний ресурс, а одна является внутренней ссылкой на элемент страницы;
- один маркированный список;
- один нумерованный список;
- одно изображение с заполненным атрибутом `alt`;
- одну таблицу, содержащую не менее трёх строк и трёх столбцов;
- блок карточек контента, оформленный с использованием класса `.card`.

После создания HTML-разметки страница должна быть оформлена с помощью внешнего CSS-файла. Необходимо задать шрифты, цвета, отступы, оформить шапку и навигацию, выровнять меню с помощью Flexbox или Grid, создать карточки контента и обеспечить адаптивное отображение страницы на разных ширинах экрана.

- содержать головную часть `head` с метаданными: кодировкой UTF-8, параметром `viewport` и заголовком страницы;
- содержать видимую часть `body`;
- отображать заголовок вкладки браузера;
- содержать один заголовок `h1`;
- содержать не менее двух заголовков `h2` или `h3`;

- содержать блок карточек с классом `.card`;
- быть подключена к внешнему CSS-файлу через элемент `link`;
- иметь единое визуальное оформление: шрифты, цвета, отступы, поля и размеры элементов должны выглядеть согласованно;
- использовать `box-sizing: border-box` для основных контейнеров и элементов карточек;
- содержать оформленную шапку или навигационный блок;
- содержать меню, выровненное с помощью Flexbox или Grid;
- содержать ссылки меню, которые изменяют внешний вид при наведении;
- отображать карточки в несколько колонок или в виде сетки согласно варианту;
- корректно отображаться на широком экране;
- корректно перестраиваться на узких экранах в соответствии с требованиями варианта;
- не иметь горизонтальной полосы прокрутки на мобильных ширинах экрана, если иное не вызвано демонстрационной ошибкой;
- сохранять читаемость текста, достаточные отступы и понятную структуру контента на всех проверяемых ширинах окна браузера.

### 3. Пошаговое описание выполнения

#### Шаг 1. Создание каталога проекта

Создайте отдельный каталог проекта, например:

```text
web-page/
```

Внутри каталога создайте файл:

```text
index.html
```

Затем создайте каталог `css`, а внутри него файл `style.css`:

```text
web-page/
│
├── index.html
└── css/
    └── style.css
```

Если на странице будет использоваться изображение, создайте каталог `images`:

```text
web-page/
│
├── index.html
├── css/
│   └── style.css
└── images/
    └── image.jpg
```

---

#### Шаг 2. Создание базовой структуры HTML-документа

Откройте файл `index.html` и добавьте базовую структуру документа:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Название страницы</title>
</head>
<body>

</body>
</html>
```

Замените `Название страницы` на заголовок, который будет отображаться на вкладке браузера.

---

#### Шаг 3. Добавление шапки и навигации

Внутри элемента `body` добавьте шапку сайта и навигационный блок:

```html
<header class="site-header">
    <h1>Название страницы</h1>

    <nav class="main-nav">
        <ul>
            <li><a href="#about">О проекте</a></li>
            <li><a href="#items">Каталог</a></li>
            <li><a href="#table">Таблица</a></li>
        </ul>
    </nav>
</header>
```

Внутренние ссылки ведут к элементам страницы, у которых задан соответствующий атрибут `id`.

---

#### Шаг 4. Добавление основного контента

Добавьте основную часть документа:

```html
<main class="content">

</main>
```

Внутри `main` разместите несколько смысловых разделов. Например:

```html
<section id="about" class="about">
    <h2>О проекте</h2>
    <p>Краткое описание проекта.</p>
    <p>Дополнительная информация о содержании страницы.</p>
    <p>Приглашение или пояснение для пользователя.</p>
</section>
```

Добавьте второй и третий разделы:

```html
<section id="items" class="cards-section">
    <h2>Карточки</h2>
    <div class="cards">
        <article class="card">
            <h3>Первый элемент</h3>
            <p>Описание первого элемента.</p>
        </article>

        <article class="card">
            <h3>Второй элемент</h3>
            <p>Описание второго элемента.</p>
        </article>

        <article class="card">
            <h3>Третий элемент</h3>
            <p>Описание третьего элемента.</p>
        </article>
    </div>
</section>
```

Добавьте раздел с таблицей:

```html
<section id="table" class="table-section">
    <h2>Таблица</h2>

    <table>
        <tr>
            <th>Первый столбец</th>
            <th>Второй столбец</th>
            <th>Третий столбец</th>
        </tr>
        <tr>
            <td>Данные</td>
            <td>Данные</td>
            <td>Данные</td>
        </tr>
        <tr>
            <td>Данные</td>
            <td>Данные</td>
            <td>Данные</td>
        </tr>
    </table>
</section>
```

---

#### Шаг 5. Добавление ссылок, списков и изображения

Добавьте на страницу не менее трёх ссылок. Пример:

```html
<p>
    <a href="#about">Перейти к описанию</a><br>
    <a href="#items">Перейти к карточкам</a><br>
    <a href="https://example.com" target="_blank">Внешний ресурс</a>
</p>
```

Добавьте маркированный список:

```html
<h3>Категории</h3>
<ul>
    <li>Первая категория</li>
    <li>Вторая категория</li>
    <li>Третья категория</li>
</ul>
```

Добавьте нумерованный список:

```html
<h3>Порядок действий</h3>
<ol>
    <li>Откройте страницу.</li>
    <li>Изучите содержание.</li>
    <li>Проверьте ссылки.</li>
</ol>
```

Добавьте изображение:

```html
<img src="images/image.jpg" alt="Описание изображения" width="600">
```

Если изображение отсутствует, можно использовать файл-заглушку, но атрибут `alt` должен быть обязательно заполнен.

---

#### Шаг 6. Подключение CSS-файла

В элементе `head` подключите файл стилей:

```html
<link rel="stylesheet" href="css/style.css">
```

Полный пример головной части:

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Название страницы</title>
    <link rel="stylesheet" href="css/style.css">
</head>
```

---

#### Шаг 7. Базовая настройка стилей

Откройте файл `css/style.css` и добавьте базовые правила:

```css
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

body {
    font-family: Arial, sans-serif;
    line-height: 1.6;
    background-color: #ffffff;
    color: #222222;
}

.site-header {
    padding: 20px;
    background-color: #f4f4f4;
    border-bottom: 1px solid #dddddd;
}

.content {
    max-width: 1200px;
    margin: 0 auto;
    padding: 20px;
}
```

Замените цвета, шрифты и размеры так, чтобы они соответствовали вашему варианту.

---

#### Шаг 8. Оформление навигации

Для горизонтального меню используйте Flexbox:

```css
.main-nav ul {
    display: flex;
    flex-wrap: wrap;
    gap: 16px;
    list-style: none;
}

.main-nav a {
    display: block;
    padding: 10px 14px;
    text-decoration: none;
    color: #222222;
    border-radius: 6px;
}

.main-nav a:hover {
    background-color: #e0e0e0;
    color: #000000;
}
```

Если по варианту требуется вертикальное меню, используйте:

```css
.main-nav ul {
    display: flex;
    flex-direction: column;
    gap: 12px;
}
```

---

#### Шаг 9. Оформление карточек

Добавьте стиль для класса `.card`:

```css
.card {
    background-color: #ffffff;
    border: 1px solid #dddddd;
    border-radius: 10px;
    padding: 20px;
    box-shadow: 0 2px 6px rgba(0, 0, 0, 0.08);
}

.card h3 {
    margin-bottom: 10px;
    font-size: 1.2rem;
}

.card p {
    color: #444444;
}
```

Разместите карточки в контейнере. Например, с использованием Grid:

```css
.cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
    margin-top: 20px;
}
```

Или с использованием Flexbox:

```css
.cards {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
    margin-top: 20px;
}

.card {
    flex: 1 1 calc(33.333% - 20px);
}
```

---

#### Шаг 10. Добавление адаптивности

Добавьте медиазапрос для узких экранов:

```css
@media (max-width: 768px) {
    .site-header {
        padding: 16px;
    }

    .main-nav ul {
        flex-direction: column;
        align-items: flex-start;
    }

    .cards {
        grid-template-columns: 1fr;
    }

    .card {
        flex: 1 1 100%;
    }
}
```

Если вариант требует дополнительную точку перестроения, добавьте отдельный медиазапрос. Например:

```css
@media (max-width: 900px) {
    .cards {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (max-width: 600px) {
    .cards {
        grid-template-columns: 1fr;
    }
}
```

---

#### Шаг 11. Проверка страницы

Откройте страницу в браузере и проверьте:

- заголовок вкладки браузера;
- наличие основного заголовка и подзаголовков;
- корректное отображение абзацев;
- работоспособность внутренних и внешних ссылок;
- наличие маркированного и нумерованного списков;
- отображение изображения;
- наличие таблицы размером не менее трёх строк и трёх столбцов;
- оформление карточек;
- работу меню;
- изменение макета при уменьшении ширины окна.

Для проверки адаптивности используйте инструменты разработчика в браузере. В них можно изменять ширину области просмотра и смотреть, как срабатывают медиазапросы.

### Задания

1. Создайте каталог проекта и файл `index.html`.
2. Создайте каталог `css` и файл `style.css`.
3. Оформите корректную структуру HTML-документа:
   - объявление `<!DOCTYPE html>`;
   - элемент `html` с атрибутом `lang="ru"`;
   - головную часть `head`;
   - метаданные: кодировка UTF-8, `viewport`, заголовок страницы;
   - видимую часть `body`.
4. Добавьте на страницу текстовую структуру по своему варианту:
   - один заголовок `h1`;
   - не менее двух заголовков `h2` или `h3`;
   - не менее трёх абзацев текста.
5. Добавьте навигационные элементы:
   - не менее трёх гиперссылок;
   - хотя бы одну ссылку на внешний ресурс;
   - хотя бы одну внутреннюю ссылку на элемент страницы с использованием `id`.
6. Добавьте списки:
   - один маркированный список;
   - один нумерованный список.
7. Добавьте изображение с заполненным атрибутом `alt`.
8. Добавьте таблицу с заголовком, строками и ячейками. Таблица должна содержать не менее трёх строк и трёх столбцов.
9. Добавьте блок карточек контента с классом `.card`.
10. Подключите файл `style.css` к HTML-странице через элемент `link`.
11. Выполните базовое оформление:
    - задайте шрифт страницы;
    - задайте цвета фона и текста;
    - настройте внешние и внутренние отступы;
    - примените свойство `box-sizing: border-box` для основных контейнеров.
12. Оформите шапку и навигацию:
    - меню должно быть выровнено с помощью Flexbox или Grid;
    - ссылки в меню должны изменять стиль при наведении;
    - навигация должна соответствовать варианту.
13. Оформите карточки:
    - фон;
    - рамка или тень;
    - скругление углов;
    - внутренние отступы;
    - заголовок и текст внутри карточки.
14. Разместите карточки в контейнере с использованием Flexbox или Grid согласно варианту.
15. Добавьте адаптивность:
    - создайте медиазапрос для ширины экрана не более 768px;
    - при необходимости добавьте дополнительный медиазапрос для ширины 900px или 600px;
    - на узких экранах навигация должна становиться вертикальной или компактной, а карточки — выстраиваться в одну колонку, если это требуется по варианту.
16. Проверьте отображение страницы при разных ширинах окна браузера.
17. Подготовьте к сдаче:
    - файл `index.html`;
    - файл `css/style.css`;
    - дополнительные файлы проекта, если они используются;
    - демонстрацию страницы на широком экране;
    - демонстрацию страницы на узком экране;
    - исходный код HTML и CSS;
    - пояснение выбранного варианта и соответствие его требованиям.
