## Задание 3. Добавление новой функции

### Описание задания

Необходимо добавить в программу новую функцию, например расчёт суммы двух чисел.

### Ход выполнения

1. Добавлена функция `sum_numbers`.
2. Вызван результат функции в основной части программы.
3. Выполнена проверка работоспособности.

### Фрагмент кода

```python
def sum_numbers(a, b):
    return a + b

result = sum_numbers(5, 7)
print("Сумма чисел:", result)
```
