## Учебная задача

### 1. Формулировка задачи

Разработайте программу для оценки массы посылки и расчёта стоимости доставки.

Программа должна:

1. Запросить у пользователя массу посылки в килограммах. Масса может быть дробным числом, например `2.3`.
2. Запросить у пользователя целое число `N`, которое задаёт диапазон проверки масс от `1` до `N`.
3. Определить категорию введённой массы посылки:
   * если масса меньше или равна `0`, вывести сообщение об ошибке;
   * если масса не превышает `1` кг включительно, вывести категорию `лёгкая`;
   * если масса не превышает `5` кг включительно, вывести категорию `средняя`;
   * если масса больше `5` кг, вывести категорию `тяжёлая`.
4. Рассчитать стоимость доставки по правилам:
   * первые `1` кг стоят `100.00` рублей;
   * каждый начатый дополнительный килограмм стоит `50.00` рублей;
   * если масса меньше или равна `0`, стоимость считается равной `0.00`.
5. Реализовать функцию `delivery_cost(weight)`, которая принимает массу и возвращает стоимость доставки. Функция не должна сама выводить результат на экран.
6. Реализовать функцию `weight_category(weight)`, которая принимает массу и возвращает строку с категорией. Функция также не должна выводить результат на экран.
7. В цикле `for` перебрать массы от `1` до `N` включительно и для каждой массы вывести категорию и стоимость доставки.
8. Дополнительно вызвать функцию `delivery_cost()` несколько раз с разными аргументами и показать результаты.
9. Добавить комментарии к функциям и основным блокам программы.

Пример имени файла: `parcel.py`.

### 4. Полный код программы

```python
# Файл: parcel.py
# Программа демонстрирует работу условий, цикла for и функций.

# Функция возвращает текстовую категорию массы.
# Она не выводит результат на экран, только возвращает строку.
def weight_category(weight):
    # Если масса меньше или равна нулю, данные считаются неверными.
    if weight <= 0:
        return "некорректная"

    # Масса до 1 кг включительно относится к лёгкой категории.
    elif weight <= 1:
        return "лёгкая"

    # Масса до 5 кг включительно относится к средней категории.
    elif weight <= 5:
        return "средняя"

    # Все остальные положительные массы относятся к тяжёлой категории.
    else:
        return "тяжёлая"


# Функция возвращает стоимость доставки.
# Первые 1 кг стоят 100 рублей.
# Каждый начатый дополнительный килограмм стоит 50 рублей.
def delivery_cost(weight):
    # Если масса меньше или равна нулю, доставка не рассчитывается.
    if weight <= 0:
        return 0.0

    # Базовая стоимость за первые 1 кг.
    cost = 100.0

    # Если масса больше 1 кг, нужно рассчитать дополнительные килограммы.
    if weight > 1:
        # Дополнительная масса сверх первого килограмма.
        extra = weight - 1.0

        # Сначала берём только полные килограммы.
        extra_kg = int(extra)

        # Если после полных килограммов остался дробный остаток,
        # он считается как один начатый дополнительный килограмм.
        if extra > extra_kg:
            extra_kg = extra_kg + 1

        # Добавляем стоимость дополнительных килограммов.
        cost = cost + extra_kg * 50.0

    # Возвращаем итоговую стоимость, а не печатаем её.
    return cost


# Запрашиваем у пользователя массу посылки.
# Масса может быть дробной, поэтому используем float().
weight = float(input("Введите массу посылки в кг: "))

# Запрашиваем количество целых масс для проверки в цикле.
n = int(input("Введите N (целое число от 1 и выше): "))

# Часть 1. Проверка условий для введённой массы.
# Здесь используются if, elif и else для нескольких различных случаев.
if weight <= 0:
    print("Ошибка: масса должна быть больше нуля.")
elif weight <= 1:
    print("Категория посылки: лёгкая.")
elif weight <= 5:
    print("Категория посылки: средняя.")
else:
    print("Категория посылки: тяжёлая.")

# Если масса корректна, показываем стоимость доставки.
# Функция вызывается отдельно, результат подставляется в строку.
if weight > 0:
    print(f"Стоимость доставки введённой посылки: {delivery_cost(weight):.2f} руб.")

# Часть 2. Обработка данных в цикле.
# Если N задано неверно, цикл не выполняется.
if n <= 0:
    print("Ошибка: N должно быть целым числом больше нуля.")
else:
    print(f"Расчёт для масс от 1 до {n}:")

    # range(1, n + 1) создаёт последовательность 1, 2, ..., n.
    for mass in range(1, n + 1):
        # Для каждой массы получаем категорию и стоимость.
        category = weight_category(mass)
        cost = delivery_cost(mass)

        # Выводим промежуточный результат для каждого значения цикла.
        print(f"Масса {mass} кг: категория '{category}', стоимость {cost:.2f} руб.")

# Часть 3. Демонстрация работы функции с разными аргументами.
# Функция вызывается несколько раз с разными значениями.
print("Проверка функции delivery_cost на других значениях:")
print(f"delivery_cost(0.5) = {delivery_cost(0.5):.2f} руб.")
print(f"delivery_cost(1) = {delivery_cost(1):.2f} руб.")
print(f"delivery_cost(2.2) = {delivery_cost(2.2):.2f} руб.")
print(f"delivery_cost(6) = {delivery_cost(6):.2f} руб.")
```
