## Учебная задача

### 1. Формулировка задачи

Необходимо написать программу на Python, которая рассчитывает расход топлива на поездку и стоимость этого топлива.

Программа должна запросить у пользователя три значения:

- расстояние поездки в километрах;
- расход топлива автомобиля в литрах на 100 км;
- цену одного литра топлива.

После ввода данных программа должна вычислить:

- количество топлива, которое потребуется на поездку;
- общую стоимость топлива.

Формулы для расчёта:

```text
liters = distance * consumption / 100
cost = liters * price
```

где:

- `distance` — расстояние в километрах;
- `consumption` — расход топлива в литрах на 100 км;
- `price` — цена одного литра топлива;
- `liters` — количество литров топлива на поездку;
- `cost` — итоговая стоимость топлива.

Все числовые результаты с дробной частью нужно выводить с двумя знаками после запятой.

### 2. Ожидаемый результат

В результате работы программы пользователь должен увидеть приглашения для ввода данных, а после ввода — два результата:

- количество топлива, необходимое на поездку;
- стоимость топлива.

Пример ожидаемого вывода:

```text
Введите расстояние поездки в км: 250.5
Введите расход топлива в литрах на 100 км: 7.4
Введите цену одного литра топлива: 58.90
На поездку потребуется 18.54 л топлива.
Стоимость топлива составит 1091.83 руб.
```

Программа должна корректно работать как с целыми, так и с дробными значениями.

### 4. Полный код программы

```python
# Программа рассчитывает количество топлива на поездку и стоимость этого топлива.
# Входные данные:
# distance - расстояние поездки в километрах;
# consumption - расход топлива в литрах на 100 км;
# price - цена одного литра топлива.

# Запрашиваем у пользователя расстояние поездки и преобразуем строку в число float
distance = float(input("Введите расстояние поездки в км: "))

# Запрашиваем у пользователя расход топлива и преобразуем строку в число float
consumption = float(input("Введите расход топлива в литрах на 100 км: "))

# Запрашиваем у пользователя цену одного литра топлива и преобразуем строку в число float
price = float(input("Введите цену одного литра топлива: "))

# Формула расчёта количества топлива:
# чтобы найти расход на поездку, нужно расстояние умножить на расход на 100 км,
# а затем разделить на 100
liters = distance * consumption / 100

# Формула расчёта стоимости топлива:
# количество литров умножается на цену одного литра
cost = liters * price

# Выводим количество топлива с двумя знаками после запятой
print(f"На поездку потребуется {liters:.2f} л топлива.")

# Выводим стоимость топлива с двумя знаками после запятой
print(f"Стоимость топлива составит {cost:.2f} руб.")
```

### 5. Как проверить корректность выполнения

Проверку нужно выполнять в консоли. Запустите программу и введите данные из контрольных наборов.

#### Набор 1. Целые значения

Ввод:

```text
100
8
60
```

Ожидаемый результат:

```text
На поездку потребуется 8.00 л топлива.
Стоимость топлива составит 480.00 руб.
```

Пояснение расчёта:

```text
100 * 8 / 100 = 8
8 * 60 = 480
```

#### Набор 2. Дробные значения

Ввод:

```text
250.5
7.4
58.90
```

Ожидаемый результат:

```text
На поездку потребуется 18.54 л топлива.
Стоимость топлива составит 1091.83 руб.
```

Пояснение расчёта:

```text
250.5 * 7.4 / 100 = 18.537
18.537 * 58.90 = 1091.8293
```

После округления до двух знаков после запятой получается:

```text
18.54
1091.83
```

#### Набор 3. Нулевое расстояние

Ввод:

```text
0
10
50
```

Ожидаемый результат:

```text
На поездку потребуется 0.00 л топлива.
Стоимость топлива составит 0.00 руб.
```

Пояснение расчёта:

```text
0 * 10 / 100 = 0
0 * 50 = 0
```

Программа считается выполненной корректно, если:

- пользовательские данные запрашиваются через `input()`;
- входные данные преобразуются в `float`;
- расчёты выполняются с использованием переменных;
- результаты выводятся с двумя знаками после запятой;
- программа корректно работает на целых и дробных значениях.
