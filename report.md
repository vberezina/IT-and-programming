# Рекомендации по отчету

[Пример отчета в формате `.md`](report/report_example.md).

## Структура папки для отчёта

Скриншоты находятся в папке `screenshots`:

- `task1.png`
- `task2.png`
- `task3.png`




Желательно разместить файлы так:

```text
lab-report/
│
├── report.md
│
└── screenshots/
    ├── task1.png
    ├── task2.png
    └── task3.png
```

В Markdown изображения подключаются так:

```markdown
![Задание 1. Запуск программы](screenshots/task1.png)
```

Путь должен быть относительным, чтобы при конвертации в PDF картинки подтянулись корректно.

# Конвертация Markdown в PDF в VS Code

## Вариант 1. Через плагин Markdown PDF

Это самый простой вариант.

### 1. Установите расширение

1. Откройте VS Code.
2. Перейдите во вкладку **Extensions**.
3. Найдите расширение:

```text
Markdown PDF
```

Автор обычно: `yzane`.

4. Нажмите **Install**.

---

### 2. Откройте файл отчёта

Откройте файл:

```text
report.md
```

---

### 3. Запустите экспорт в PDF

Нажмите:

```text
Ctrl + Shift + P
```

или

```text
F1
```

Введите команду:

```text
Markdown PDF: Export (pdf)
```

Выберите её.

---

### 4. Дождитесь завершения конвертации

После завершения рядом с файлом `report.md` появится файл:

```text
report.pdf
```

---

## Вариант 2. Через Markdown Preview Enhanced

Этот плагин тоже позволяет экспортировать Markdown в PDF и удобно показывает предпросмотр.

### 1. Установите расширение

Найдите в Extensions:

```text
Markdown Preview Enhanced
```

Установите его.

---

### 2. Откройте предпросмотр

Откройте `report.md` и нажмите:

```text
Ctrl + Shift + V
```

или кликните правой кнопкой мыши по файлу и выберите:

```text
Open Preview
```

---

### 3. Экспортируйте в PDF

В окне предпросмотра нажмите правой кнопкой мыши и выберите:

```text
Chrome (Puppeteer) -> PDF
```

или:

```text
Export -> PDF
```

Если такой пункт недоступен, может понадобиться установленный браузер/зависимость, но обычно проще использовать **Markdown PDF**.

---

## Рекомендуемый способ

Для студенческого отчёта лучше использовать:

```text
Markdown PDF
```

Он проще и подходит для быстрого экспорта.

---

## Если изображения не отображаются в PDF

Проверьте следующее:

1. Картинки лежат в папке `screenshots`.
2. Пути в `report.md` указаны правильно:

```markdown
![Задание 1](screenshots/task1.png)
```

3. Файл называется именно так, как указано в пути.
4. В путях лучше не использовать пробелы и кириллицу.

Правильно:

```text
screenshots/task1.png
```

Нежелательно:

```text
screenshots/Задание 1.png
```
